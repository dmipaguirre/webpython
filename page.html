InicioListas

Métodos para Listas (list)

Las listas son secuencias mutables y ordenadas que permiten elementos duplicados. Son la estructura de datos más utilizada en Python para colecciones de tamaño variable.

  • Mutable
  • Secuencia ordenada
  • Permite duplicados
  • Indexada por posición

append()

Essential ★¡Copiado!
list.append(x)

DevuelveNone

Añade un elemento al final de la lista, sin modificar los demás.

xobject
Elemento que se agrega al final de la lista.
python
frutas = ["manzana", "pera"]
frutas.append("naranja")
print(frutas)
# ['manzana', 'pera', 'naranja']

extend()

Essential ★¡Copiado!
list.extend(iterable)

DevuelveNone

Agrega todos los elementos de un iterable al final de la lista.

iterableiterable
Colección (lista, tupla, rango, string) cuyos elementos se agregan.
python
numeros = [1, 2, 3]
numeros.extend([4, 5, 6])
print(numeros)
# [1, 2, 3, 4, 5, 6]

insert()

Regular¡Copiado!
list.insert(i, x)

DevuelveNone

Inserta un elemento en la posición indicada por el índice i.

iint
Índice donde se inserta el elemento.
xobject
Elemento que se inserta en la lista.
python
colores = ["rojo", "azul"]
colores.insert(1, "verde")
print(colores)
# ['rojo', 'verde', 'azul']

remove()

Essential ★¡Copiado!
list.remove(x)

DevuelveNone

Elimina la primera aparición del elemento x; lanza ValueError si no existe.

xobject
Elemento que se busca y elimina de la lista.
python
frutas = ["manzana", "pera", "manzana"]
frutas.remove("manzana")
print(frutas)
# ['pera', 'manzana']

pop()

Essential ★¡Copiado!
list.pop([i])

Devuelveobject

Elimina y devuelve el elemento de la lista; por defecto el último.

iintopcional
Índice del elemento a eliminar. Si se omite, se elimina el último.
python
pila = [10, 20, 30]
ultimo = pila.pop()
print(ultimo)  # 30
print(pila)    # [10, 20]

clear()

Regular¡Copiado!
list.clear()

DevuelveNone

Elimina todos los elementos de la lista, dejándola vacía.

python
lista = [1, 2, 3]
lista.clear()
print(lista)
# []

index()

Regular¡Copiado!
list.index(x[, start[, end]])

Devuelveint

Devuelve el índice de la primera aparición de x; lanza ValueError si no se encuentra.

xobject
Elemento cuya posición se busca.
startintopcional
Índice inicial de la búsqueda.
endintopcional
Índice final (exclusivo) de la búsqueda.
python
numeros = [3, 7, 7, 12]
print(numeros.index(7))     # 1
print(numeros.index(7, 2))  # 2

count()

Regular¡Copiado!
list.count(x)

Devuelveint

Cuenta cuántas veces aparece el elemento x en la lista.

xobject
Elemento que se busca para contar sus apariciones.
python
notas = [4, 5, 4, 3, 5, 4]
print(notas.count(4))
# 3

sort()

Essential ★¡Copiado!
list.sort(*, key=None, reverse=False)

DevuelveNone

Ordena la lista in-place según el criterio indicado por key.

keycallableopcional
Función que devuelve un valor de ordenación para cada elemento.
reverseboolopcional
Si es True, ordena de forma descendente.
python
numeros = [5, 2, 8, 1]
numeros.sort()
print(numeros)  # [1, 2, 5, 8]

numeros.sort(reverse=True)
print(numeros)  # [8, 5, 2, 1]

reverse()

Regular¡Copiado!
list.reverse()

DevuelveNone

Invierte el orden de los elementos de la lista en su lugar.

python
numeros = [1, 2, 3]
numeros.reverse()
print(numeros)
# [3, 2, 1]

copy()

Regular¡Copiado!
list.copy()

Devuelvelist

Devuelve una copia superficial (shallow copy) de la lista.

python
original = [1, 2, 3]
copia = original.copy()
copia.append(4)
print(original)  # [1, 2, 3]
print(copia)     # [1, 2, 3, 4]

InicioTuplas

Métodos para Tuplas (tuple)

Las tuplas son secuencias inmutables y ordenadas. Al no poder modificarse tras su creación, además de sus dos métodos nativos se usan operadores integrados para trabajar con ellas.

  • Inmutable
  • Secuencia ordenada
  • Permite duplicados
  • Indexada por posición

Sin resultados para «» en Tuplas.

InicioDiccionarios

Métodos para Diccionarios (dict)

Los diccionarios almacenan pares clave-valor con acceso por hash. Las claves deben ser inmutables y únicas, mientras que los valores pueden ser de cualquier tipo.

  • Mutable
  • Orden de inserción
  • Claves únicas
  • Acceso por hash

Sin resultados para «» en Diccionarios.

InicioConjuntos

Métodos para Conjuntos (set)

Los conjuntos almacenan elementos únicos sin orden garantizado. Su implementación interna está basada en tablas hash, lo que hace muy rápidas las operaciones de pertenencia.

  • Mutable
  • Sin orden
  • Sin duplicados
  • Elementos únicos

Sin resultados para «» en Conjuntos.
